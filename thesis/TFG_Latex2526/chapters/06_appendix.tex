\section{System Usability Scale Questionnaire}
\label{app:sus-questionnaire}

The following items were administered to medical expert participants after a guided session with the Block~4 dashboard (\Cref{subsec:validation-ux}). Each statement was rated on a five-point Likert scale (1 = strongly disagree, 5 = strongly agree). Item wording follows the standard SUS format~\cite{brooke1996}.

\begin{enumerate}
  \item I think that I would like to use this coronary viewer frequently in clinical practice.
  \item I found the system unnecessarily complex.
  \item I thought the Dashboard was easy to use and intuitive.
  \item I think that I would need the support of a technical person to be able to use this system autonomously.
  \item I found the various functions in this viewer (interactive 3D meshes, profile plots, clinical metrics) were well integrated.
  \item I thought there was too much inconsistency in this system.
  \item I would imagine that most medical professionals would learn to use this system very quickly.
  \item I found the system very cumbersome to use.
  \item I felt very confident using the system to analyze artery anatomy and CAD-RADS estimation.
  \item I needed to learn a lot of things before I could get going with this system.
\end{enumerate}

\textbf{Optional open question.}
\begin{quote}
  Do you have any additional comments, suggestions for improvement, or features you would like to see in the future?
\end{quote}

Scores were computed using the standard SUS conversion described in \Cref{subsec:validation-ux}.
